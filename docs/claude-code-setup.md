# Claude Code setup

Everything lives under `.claude/` and is committed. Project rules: `CLAUDE.md` (workflow) and `AGENTS.md` (project facts).

## Hooks (`.claude/settings.json`, scripts in `.claude/hooks/`)

| Hook                  | Event                     | What it does                                                                                                                                                                                                                                                                                                  |
| --------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `block-dangerous.mjs` | PreToolUse (Bash)         | Exit 2 (blocks) for recursive forced deletes, force push, push to main/master, hard reset, any `.env*` file except `.env.example`, `curl`/`wget`, and the skip-permissions flag. Fails open on malformed input. Matches command text, so it can false-positive when a command only mentions a blocked string. |
| `format.mjs`          | PostToolUse (Edit, Write) | Runs Prettier on the changed file; silent if Prettier is missing.                                                                                                                                                                                                                                             |
| `quality-gate.mjs`    | Stop                      | Runs `pnpm typecheck` and `pnpm test`; exit 2 on failure so Claude fixes it before finishing.                                                                                                                                                                                                                 |

## Permissions

| Group   | Rules                                                                                                                                    |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `allow` | `pnpm lint/typecheck/test/build/format`, `openspec`, read-only git plus `git add` and `git commit`.                                      |
| `ask`   | `git push`, `pnpm install/add`, Prisma migrate, `docker compose`.                                                                        |
| `deny`  | Reading `.env*` and `secrets/**`; `curl`, `wget`; force push (`--force`, `--force-with-lease`, `-f`); push to `main`/`master`; `rm -rf`. |

The hook and the deny list overlap on purpose: two layers for the same risks.

## Skills (`.claude/skills/`)

- `api-conventions`: `/api/v1` conventions (status codes, error shape, pagination, validation, authorization) from SDS sections 4 and 6.
- `openspec-*`: OpenSpec workflow skills (generated by `openspec`).

## Commands and agents

- `.claude/commands/opsx/`: the 12 `/opsx:*` commands (explore, propose, update, apply, verify, sync, archive, and others). These are the only workflow commands.
- `.claude/agents/`: sub-agent definitions, owned by DEV-1003.

## Tests and evidence

- Tests: `scripts/tests/claude-permissions.test.mjs`, `claude-hooks.test.mjs`, `claude-skill.test.mjs` (run with `pnpm test`).
- Evidence of blocked actions: `docs/evidence/DEV-1002/`.
